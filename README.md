# Rename GUI

Простое приложение для Windows на Python с графическим интерфейсом (PyQt6), которое переименовывает файлы в выбранной папке — добавляя **ровно одну букву "к"** в начало имени каждого файла.

---

## 🔧 Возможности

- Выбор папки через удобный графический интерфейс.
- Переименование всех файлов в выбранной папке.
- Удаление всех лишних `к` в начале имени и добавление одной.
- Поддержка Windows.
- Автоматическая сборка `.exe` файла через GitHub Actions.

---

## 🖼️ Пример

Было:

---
- ккфото.jpg
- документ.txt
- ккктекст.docx



Станет:

---


- кфото.jpg
- кдокумент.txt
- ктекст.docx



## 🚀 Как запустить (локально)

1. Установите зависимости:
    ```bash
    pip install PyQt6
    ```

2. Запустите:
    ```bash
    python rename_gui.py
    ```

---

## 🏗️ Сборка `.exe` через GitHub Actions

В проекте настроен автосборщик для Windows. При каждом `push` в ветку `Master` или `pull_request` происходит:

- Установка Python 3.12
- Установка зависимостей из `requirements.txt` (если есть)
- Установка PyInstaller
- Сборка `.exe` файла из `rename_gui.py`
- Загрузка артефакта `RenameGui.exe`


## 📦 Зависимости

* Python ≥ 3.10
* PyQt6

---

## 📁 Сборка вручную

Если хочешь собрать `.exe` вручную без GitHub Actions:

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name RenameGui rename_gui.py
```

Собранный `.exe` появится в папке `dist/`.
